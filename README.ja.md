# HIIT Timer

高強度インターバルトレーニング（HIIT）用のシンプルなブラウザベースのタイマーです。標準的なタバタ式ワークアウト用に事前設定されています。

## デモ

[**https://github.com/code4fukui/hiittimer](https://code4fukui.github.io/hiittimer/)

タイマーは視覚的にわかりやすい合図を提供します。高強度の運動インターバル中は背景が赤色になり、休憩期間中は白色になります。

## 機能

*   **ワークアウト構成:** 20秒の運動と10秒の休憩を8ラウンド行います。
*   **視覚的な合図:** 運動中は背景色が赤色に、休憩中は白色に変化します。
*   **音声フィードバック:** 開始時の3秒間のカウントダウン、各インターバルの残り数秒、およびワークアウト完了時に効果音が鳴ります。
*   **シンプルなインターフェース:** 大きなタイマー、ラウンドカウンター、そして1つの「START」ボタンのみの構成です。

## 使い方

1.  ウェブブラウザで[デモページ](https://code4fukui.github.io/hiittimer/)を開きます。
2.  「START」ボタンをクリックしてタイマーを開始します。
