# HIIT Timer

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple, browser-based timer for High-Intensity Interval Training (HIIT), pre-configured for a standard Tabata-style workout.

## Demo

[**https://github.com/code4fukui/hiittimer](https://code4fukui.github.io/hiittimer/)

The timer provides clear visual cues. The background is red during high-intensity work intervals and white during rest periods.

## Features

*   **Workout Structure:** 8 rounds of 20 seconds of work followed by 10 seconds of rest.
*   **Visual Cues:** The background color changes to red for work periods and white for rest periods.
*   **Audio Feedback:** Sound effects signal the initial 3-second countdown, the final seconds of each interval, and the completion of the workout.
*   **Simple Interface:** A large timer, a round counter, and a single "START" button.

## Usage

1.  Open the [demo page](https://code4fukui.github.io/hiittimer/) in a web browser.
2.  Click the "START" button to begin the timer.
